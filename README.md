# Тестирование API Яндекс Самокат

Автотесты API учебного сервиса Яндекс Самокат: ручки создания курьера,
логина, создания заказа и списка заказов.

## Что проверяется

- **Создание курьера** (`POST /api/v1/courier`): успешное создание и ответ
  `{"ok": true}`; дубликат логина — 409; без логина или пароля — 400.
- **Логин курьера** (`POST /api/v1/courier/login`): успешный вход возвращает
  `id`; без обязательных полей — ошибка; неверный логин/пароль или
  несуществующий пользователь — 404.
- **Создание заказа** (`POST /api/v1/orders`): цвет BLACK, GREY, оба или
  без цвета (параметризация); в ответе есть `track`.
- **Список заказов** (`GET /api/v1/orders`): в ответе список заказов.
