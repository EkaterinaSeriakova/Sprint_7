## Баг 1. Логин курьера без пароля — 504 вместо 400

**Ручка:** POST /api/v1/courier/login

**Шаги:** отправить запрос на логин с телом {"login": "<валидный логин>"} (без поля password)

**Ожидаемый результат:** 400, message «Недостаточно данных для входа»

**Фактический результат:** 504 Gateway Timeout

**Воспроизводимость:** стабильно, 100%
